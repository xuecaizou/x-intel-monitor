X-Intel · X(Twitter) 情报监控台

独立监控 X 账号威胁情报：三级降级抓取 → AI 研判/翻译/地理标签 → 四通道推送 · v6
内建帮助文档控制台

功能特性

监控源 01 · X 账号（三级降级 · 必须走代理）

  • A · X syndication 官方接口（免登录）
  • B · Nitter RSS：可用实例缓存 + twiiit.com 轮换自动发现
  • C · X 登录 Cookie 直连 GraphQL（实验性）
  • 每账号独立监控频率（5 分钟~2 小时/跟随全局）
  • 增量抓取：置顶推文 id 短路，未更新不重复处理
  • AI 实时开关：一键启停自动研判/翻译
  • 抓取日志：每轮分层追踪明细持久化（500 轮）

推文管理

  • 卡片/列表双视图（记忆选择）· 左侧菜单视图切换（48px ⇄ 220px 记忆）
  • 推文截图：服务端代理拉取 X 图片 CDN
  • 收藏 / 已读 / 忽略 + 状态筛选
  • 勾选批量：已读/忽略/删除/批量翻译/批量研判
  • 一键清理（保留 1~30 天，收藏永久保留）
  • 雪花 ID 排序（全局时间有序）+ 本地时区显示

AI 能力

  • 厂商预设：DeepSeek/GLM/Kimi/Qwen/OpenAI/Ollama/自定义
  • 监控源 02 · RSS：feedburner/通用 RSS/Atom，guid 增量短路，条目复用 AI/推送管道
  • 智能研判：类型/等级/评估/处置建议/IOC/置信度
  • 智能翻译：标题摘要 + 完整中文（专有名词不译）
  • 地理行业标签：国家→省州→城市 + 涉事单位 + 行业
  • 情报分类：16 类标准（预警/参考/舆论/政策/动态/态势/主体+各类攻击线索）
  • 模型列表拉取：调厂商 /models 填充下拉（仍可手输）
  • 自动处理 + 手动按钮 + 批量 + 补标；prompt 中英对照

推送

  • 四通道 × 多实例：每通道可加 N 个推送目标（如 5 个企微群）
  • 实例级推送筛选（等级/国家/行业/关键词，叠加全局过滤）· 企微限频自动退避
  • 摘要合并（≤8 条）+ critical/high 即时单推（企微自动附截图原图）
  • 推送过滤四维：等级/国家/行业/关键词白名单
  • 报告交付按通道能力分发（企微附件两步法/钉钉摘要/PushPlus 富文本/WxPusher 卡片）
  • 凭据页面编辑（脱敏），留空=模拟模式

报告任务（写作桥接）

  • 勾选推文生成线索包 → 外部 report-writer Agent 按规范写作
  • claim 原子领取（并发双领 409）· heartbeat/abort
  • 交付后系统复跑机械门禁（不信任 Agent 自报）
  • 六状态状态机；auto_push 可选；推送按通道能力分发

快速开始

pip install -r requirements.txt
python run.py
# 控制台 http://本机IP:8083（默认监听 0.0.0.0，局域网可访问）
# 帮助文档 http://本机IP:8083/help   Swagger http://本机IP:8083/docs

首次启动自动建库（SQLite data/xintel.db）并预置 @DailyDarkWeb 监控账号；页面改动（AI Key/通道凭据/开关/过滤规则）持久化到 data/runtime.json，优先级高于 config.yaml。

网络要求：X 相关域名直连会被 DNS 污染（实测解析到 Facebook IP 段），network.proxy 必须指向可用本地代理（默认 socks5://127.0.0.1:10808）。AI 接口默认直连（国内厂商无需代理）。

系统架构

配置说明（config.yaml；页面改动优先存 data/runtime.json）

server:   { host: 0.0.0.0, port: 8083 }        # 0.0.0.0 = 局域网可访问
fetch:    { interval_minutes: 15, timeout_seconds: 25, retries: 1 }
network:  { proxy: "socks5://127.0.0.1:10808" } # 全局代理（X 源必须）
x:
  strategy: "auto"                # auto = syndication → Nitter → Cookie 直连
  show_replies: true
  max_items: 20                   # 每账号每轮最多入库条数
  nitter_instances: ["nitter.meowing.monster"]   # 兜底实例（会随时间变化）
  auth_token: ""                  # 可选：X 登录 Cookie（第三级直连）
  ct0: ""
ai:
  enabled: true
  base_url: "https://api.deepseek.com/v1"   # OpenAI 兼容；页面有厂商预设
  api_key: ""
  model: "deepseek-chat"
  auto_analyze: true              # 新推文自动研判+翻译
  auto_limit: 10                  # 每轮自动处理上限（控成本）
  max_tokens: 1200
  proxy: ""                       # AI 接口可选代理
channels:
  wecom:    { enabled: true,  webhook: "" }
  dingtalk: { enabled: true,  webhook: "", secret: "" }
  pushplus: { enabled: false, token: "" }
  wxpusher: { enabled: false, app_token: "", uid: "" }
push:
  digest_max_items: 8
  filters: { min_severity: "", countries: "", industries: "", keywords: "" }

REST API 参考

交互式文档（Swagger UI）：/docs · OpenAPI：/openapi.json · 全部接口无鉴权，仅限内网。

推文数据与管理

GET/api/tweets?screen_name=&severity=&country=&industry=&q=&status=&limit=&offset= — 推文流。status：all（未忽略）/ unread / read / ignored / starred。条目含 text/title_zh/text_zh/ai_*/geo_*/org/industry/media_url/starred/read/ignored。

GET/api/media?url=… — 推文截图代理（仅 pbs/ton.twimg.com，服务端走抓取代理拉图）。

GET/api/facets — 国家与行业去重计数。

POST/api/tweets/{id}/flag — {"starred":true,"read":true,"ignored":false} 任意组合。

POST/api/tweets/batch — {"ids":[…],"op":"read·unread·ignore·unignore·delete·ai_translate·ai_analyze"}（批量 AI ≤20 条串行）。

POST/api/tweets/cleanup — {"keep_days":1|2|3|7|30}，收藏永久保留。

AI 独立接口（不落库，供外部工具 / AI Agent 调用）

POST/api/ai/analyze — {"text":"…","screen_name":"可选"} → 结构化研判（threat_type / severity / confidence / assessment / recommendations[] / actors[] / iocs[] / country / province / city / organizations[] / industry / model）

POST/api/ai/translate — {"text":"…"} → {title_zh, text_zh}

POST/api/ai/tag — {"text":"…"} → {country, province, city, organizations[], industry}

POST/api/ai/test — 连通测试 · POST/api/ai/backfill?limit=10 — 批量补标 · GET/api/ai/config（Key 脱敏）/ PUT/api/ai/config · GET/api/ai/models — 拉取厂商 /models 模型列表

监控账号

GET/api/x/accounts · POST/api/x/accounts {"screen_name":"…"} · PUT/api/x/accounts/{id}（screen_name / display / fetch_minutes）· POST/api/x/accounts/{id}/toggle · DELETE/api/x/accounts/{id}

抓取 / 统计 / 推送

POST/api/fetch/run · GET/api/fetch/logs（抓取日志：分层追踪明细，保留 500 轮）· GET/api/stats（含 ai_auto_on）· GET/api/push/logs

GET/api/channels · POST/api/channels/{key}/toggle · GET/api/channels/{key}/config（脱敏）/ PUT/api/channels/{key}/config · POST/api/channels/{key}/test

GET/api/push/filters / PUT/api/push/filters（min_severity / countries / industries / keywords）

报告任务（桥接外部 report-writer Agent）

POST/api/reports/tasks — 建任务（title/keywords≥3组/tweet_ids≤50/tier 速报·完整/notes/auto_push），线索包落盘 data/report_tasks/task_<id>.json · GET/api/reports/tasks（列表）· GET/api/reports/tasks/{id}/package（Agent 取料入口）

POST/api/reports/tasks/{id}/status — {"action":"claim|heartbeat|abort"}，claim 原子领取并发双领 409 · POST/api/reports/tasks/{id}/deliver — 交付回写+系统复跑机械门禁验收（可选 word_limit；exit 0 → 已交付待推，否则待人工）· POST/api/reports/tasks/{id}/push — 人工确认推送（企微 markdown+报告交付附件，其余通道按能力分发）· DELETE/api/reports/tasks/{id}（写作中 409）

Agent / 外部工具接入

系统内建帮助页 /help 第 7、8 节提供接入指南与 5 个可直接复制的 Prompt 模板（系统接入 Prompt、每日威胁简报、定向监控分析、任意文本研判、IOC 汇总导出），模板内嵌 API 说明与字段含义，替换 {BASE} 即可粘贴给任何具备联网能力的 AI（Claude / GPT / Cursor / Dify / 本地 Agent）。

1. GET  {BASE}/api/tweets?severity=high&country=美国&limit=20   ← 拉取情报（自带中文翻译与地理标签）
2. GET  {BASE}/api/facets                                        ← 确认可选维度
3. POST {BASE}/api/ai/analyze {"text":"外部文章正文"}             ← 研判任意外部文本
4. 轮询 GET {BASE}/api/stats 的 last_fetch.at 感知增量            ← 变化后拉 /api/tweets?limit=10

常见问题

  • 抓取全失败？先确认本地代理可用（X 域名被 DNS 污染必须走代理）；出口节点切换后无需改配置。
  • AI 报 429 / 额度用尽？供应商侧额度问题，报错如实显示在推文卡上；换 Key 或充值后点卡上按钮重试，或用「补齐地区标签」批量补跑。
  • 推文为什么是英文？等 AI 自动翻译完成即显示中文块；也可手动点「翻译」。
  • 时间看不懂？页面时间已按本地时区渲染；数据库 / API 原始值统一为 GMT。
  • 安全提示：系统无鉴权，仅限内网使用；AI Key 明文存于 data/runtime.json，勿外传。
